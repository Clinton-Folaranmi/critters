# Scratch frame scripts

Hand-written scripts that shot review frames for the first cockroach and koi boards (`board-shots.mjs`, `live.mjs`, `koi-shots.mjs`), kept as examples of driving `qa/lib/chrome.mjs`. They are not checks, aren't linted or formatted, and open pages (`/cockroach/`, `/koi/` with dev hooks) that the site no longer builds: adapt before use.
